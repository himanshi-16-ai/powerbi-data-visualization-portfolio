# 📊 Power BI Analytics Dashboards Portfolio

Welcome to my Power BI analytics portfolio! This repository contains interactive dashboards built using **Microsoft Power BI** to analyze real-world datasets across sports, entertainment, and music streaming platforms.

---

## 📌 Projects Overview

### 🏏 1. Cricket IPL Analytics (RCB Focus)
A comprehensive Power BI dashboard analyzing IPL cricket match statistics, team performances, and detailed innings trends, with a specialized focus on Royal Challengers Bengaluru (RCB).

#### Key Highlights & Visuals:
- **Core Metrics:** Overview of Total Runs, Total Wickets, Total Matches, and Extra Runs.
- **Innings & Over Analysis:** Line charts tracking run distributions by over and total wickets across innings.
- **Extra Runs Breakdown:** Donut chart analyzing extra types (*wides, legbyes, byes, noballs, penalty*).
- **Match Statistics Table:** Granular tabular view displaying match IDs alongside runs, wickets, and extras.

---

### 🎬 2. Netflix Movies & TV Shows Dashboard
An interactive dashboard exploring Netflix's content catalog, analyzing release years, title ratings, content distribution, and geographic availability.

#### Key Highlights & Visuals:
- **KPI Summary:** Overview of total show IDs and cumulative rating counts.
- **Content Type Breakdown:** Donut chart comparing Movies vs. TV Shows ratio.
- **Geographic Coverage:** Interactive map visualization highlighting content distribution by country across continents.
- **Content Catalog List:** Filterable title menu with detailed attributes such as duration and director.

---

### 🎵 3. Spotify Data Dashboard
A dark-themed analytics dashboard visualizing Spotify music trends, artist popularity, album track distributions, and streaming engagement.

#### Key Highlights & Visuals:
- **Artist & Track Metrics:** Key metrics for track numbers, artist popularity scores, and total album tracks.
- **Popularity Gauges:** Semi-circular gauges tracking total artist followers, track popularity, and duration (mins).
- **Album Analysis:** Bar chart visualizing total tracks across top albums.
- **Track & Artist Distribution:** Pie/Donut charts highlighting top performing artists and individual track popularity share.

---

## 🛠️ Tools & Technologies Used

- **Business Intelligence Tool:** Microsoft Power BI Desktop
- **Data Modeling:** DAX (Data Analysis Expressions)
- **Data Transformation:** Power Query
- **Data Visualizations:** Custom Gauges, Donut Charts, Geographic Maps, Bar Charts, and KPI Cards
